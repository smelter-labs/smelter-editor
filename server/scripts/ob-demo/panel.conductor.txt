# OB Van demo — "Should AI direct live TV?", a panel played by one person.
# Three takes (one per persona) recorded against the conductor track, then
# synced as file cams. Format: see the header of scripts/ob-conductor.mjs.
#
#   node scripts/ob-demo-slides.mjs
#   node scripts/ob-conductor.mjs scripts/ob-demo/panel.conductor.txt
#
# Every line is placed to exercise one TALK rule (see the right-hand notes).
# Keep these words OUT of every other line — the director listens for them:
#   slide, next slide, as you can see, chart, diagram, on the screen   → SLIDES shot
#   question(s), q and a, q&a, applause                                → audience cam

SEGMENT The numbers
SLIDE 02-numbers.png
+0.5 HOST (turns to the screen) Let me show you why I'm excited. As you can see on the slide, the director doesn't wait for a new voice. It cuts about two hundred milliseconds before the first syllable.

+0.6 NERD That part isn't magic. It hears the audio three seconds before you do, so it's cheating a little.
+0.5 SKEPTIC (sighs) A little? That's the whole trick!

SEGMENT The debate
SLIDE 03-debate.png
# The split needs 3+ turns inside 6 s: keep each jab under ~2 s, no commas
# (TTS pauses on them), and step on each other's last word.
+0.3 NERD Every good director anticipates.     # quick back-and-forth → SPLIT
+-0.1 SKEPTIC It can't read minds.
+-0.1 NERD It reads audio.
+-0.1 SKEPTIC Audio isn't taste!
+-0.1 NERD Neither is yelling "camera two".
+-0.1 SKEPTIC That's called experience!
+0.7 HOST Okay, okay. Let's slow down. When a conversation gets heated like that, somebody decides what the viewer sees. I think that's the real job.

+0.4 HOST So let's just sit with that for a second.
+0.3 ALL ~8.5 [total silence — freeze, look thoughtful, nobody moves]

+0.2 SKEPTIC Is it still cutting? It went wide, didn't it.
+0.2 ALL ~2.5 (everyone laughs)
